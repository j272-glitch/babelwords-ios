## Phase 1: Verify Android App Has AdMob SDK

### 1.1 Check `app/build.gradle`
```gradle
dependencies {
    implementation 'com.google.android.gms:play-services-ads:22.6.0'
}
```

### 1.2 Check `AndroidManifest.xml`
```xml
<application>
    <meta-data
        android:name="com.google.android.gms.ads.APPLICATION_ID"
        android:value="ca-app-pub-9991891515643313~7514450861"/>
</application>
```

### 1.3 Check MainActivity.kt
Must have:
```kotlin
import com.google.android.gms.ads.MobileAds

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    
    // Initialize AdMob SDK
    MobileAds.initialize(this) { }
    
    // Create and register AdBridge
    val adBridge = AdBridge(this, webView)
    webView.addJavascriptInterface(adBridge, "AdBridge")
    
    webView.loadUrl("https://your-domain.replit.dev")
}
```

```kotlin
@JavascriptInterface

@JavascriptInterface
fun isRewardedAdReady(): Boolean
```

### 2.2 Test JavaScript Bridge
Add to your Android app's debug build:
```kotlin
webView.evaluateJavascript("""
    console.log('AdBridge available:', typeof window.AdBridge);
    console.log('AdBridge methods:', Object.keys(window.AdBridge || {}));
""", null)
```

## Quick Test Commands

### In Android Studio Logcat

### In Chrome DevTools (remote debugging)
```javascript
// Check bridge availability
console.log('AdBridge:', typeof window.AdBridge);

// Check methods

    console.log('showInterstitial:', typeof window.AdBridge.showInterstitial);
    console.log('showRewarded:', typeof window.AdBridge.showRewarded);

// Test ad request
if (window.adService) {

}
```
