# BabelWords – Android AAB Build Workflow Guide (v1)

A step-by-step guide to setting up the same GitHub Actions workflow structure used in LinguaVibe to produce a signed release `.aab` for the Play Store.

---

## 1. Prerequisites

| Item | Requirement |
|------|-------------|
| Android project | Must live inside an `android/` subdirectory at repo root |
| AGP version | 8.0.2 (stable — do **not** use 8.1.x or higher without testing) |
| Gradle | 8.x (wrapper in `android/gradle/wrapper/`) |
| JDK | 17 |
| compileSdk / targetSdk | **34** (pre-installed on GitHub runners — avoids `android.jar` load failure) |
| build-tools | 34.0.0 |

---

## 2. Required GitHub Secrets

Go to **Settings → Secrets and variables → Actions** and add:

| Secret name | What it holds |
|-------------|---------------|
| `ANDROID_KEYSTORE_BASE64` | Your `.jks` / `.keystore` file encoded as base64 (`base64 -i your.keystore`) |
| `ANDROID_KEYSTORE_PASSWORD` | Store password |
| `ANDROID_KEY_ALIAS` | Key alias |
| `ANDROID_KEY_PASSWORD` | Key password |

---

## 3. android/gradle.properties — Safe Baseline

```properties
org.gradle.jvmargs=-Xmx4096m -XX:MaxMetaspaceSize=1024m -Dfile.encoding=UTF-8
org.gradle.daemon=true
org.gradle.parallel=false
org.gradle.caching=false

android.useAndroidX=true
android.enableJetifier=true
android.nonTransitiveRClass=false
android.nonFinalResIds=false

android.suppressUnsupportedCompileSdk=34
android.suppressUnsupportedOptionWarnings=android.enableR8,android.enableR8.fullMode,android.enableResourceOptimizations,android.enableProguard
```

**Do NOT include** these deprecated properties — they cause build failures with AGP 8.0+:
- `android.enableIncrementalDesugaring`
- `android.r8.failOnMissingClasses`
- `android.enableNewResourceShrinker`
- `android.enableAapt2`
- `android.bundle.enableUncompressedNativeLibs`

---

## 4. android/build.gradle — SDK Version Block

```groovy
ext {
    agp_version = '8.0.2'
    kotlin_version = '1.8.10'

    compile_sdk = 34   // Must be 34 — 35 causes android.jar load failure on runners
    min_sdk = 24
    target_sdk = 34
    build_tools_version = '34.0.0'
}
```

## 5. The Workflow File

Create `.github/workflows/build-aab-v1.yml`:

```yaml
name: BabelWords Android AAB Build v1

on:
  workflow_dispatch:
    inputs:
      version_code:
        description: 'Version Code'
        required: false
        type: string
      version_name:
        description: 'Version Name (e.g., 1.0.0)'
        required: false
        default: '1.0.0'
        type: string
      create_release:
        description: 'Create GitHub Release'
        required: true
        default: true
        type: boolean
  push:
    branches: [ main ]

permissions:
  contents: write
  packages: write
  actions: read
  checks: read

env:
  GRADLE_OPTS: "-Xmx8192m -Dfile.encoding=UTF-8"
  ORG_GRADLE_PROJECT_android_useLegacyPackaging: true
  VERSION_CODE: ${{ github.event.inputs.version_code || '1' }}
  VERSION_NAME: ${{ github.event.inputs.version_name || '1.0.0' }}
  CREATE_RELEASE: ${{ github.event.inputs.create_release || 'true' }}
  ANDROID_KEYSTORE_BASE64: ${{ secrets.ANDROID_KEYSTORE_BASE64 }}
  ANDROID_KEYSTORE_PASSWORD: ${{ secrets.ANDROID_KEYSTORE_PASSWORD }}
  ANDROID_KEY_ALIAS: ${{ secrets.ANDROID_KEY_ALIAS }}
  ANDROID_KEY_PASSWORD: ${{ secrets.ANDROID_KEY_PASSWORD }}
  ANDROID_HOME: /usr/local/lib/android/sdk
  ANDROID_SDK_ROOT: /usr/local/lib/android/sdk

jobs:
  build-aab:
    name: Build BabelWords Release AAB
    runs-on: ubuntu-latest
    timeout-minutes: 45

    steps:
      # ── 1. Checkout ──────────────────────────────────────────────
      - name: Checkout Repository
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      # ── 2. JDK ───────────────────────────────────────────────────
      - name: Setup JDK 17
        uses: actions/setup-java@v4
        with:
          java-version: '17'
          distribution: 'temurin'

      # ── 3. Android SDK (API 34 only — pre-installed & reliable) ──
      - name: Setup Android SDK
        run: |
          yes | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --licenses || true
          $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager \
            "platform-tools" \
            "platforms;android-34" \
            "build-tools;34.0.0" \
            "extras;android;m2repository" \
            "extras;google;m2repository"
          echo "✅ Android SDK ready"

      # ── 4. Gradle wrapper ────────────────────────────────────────
      - name: Setup Gradle Wrapper
        run: |
          cd android
          mkdir -p gradle/wrapper
          chmod +x gradlew 2>/dev/null || true

          # Download wrapper jar if missing or corrupted (< 50 KB)
          JAR=gradle/wrapper/gradle-wrapper.jar
          JAR_SIZE=$(stat -c%s "$JAR" 2>/dev/null || echo 0)
          if [ ! -f "$JAR" ] || [ "$JAR_SIZE" -lt 50000 ]; then
            echo "Downloading gradle-wrapper.jar..."
            wget -q https://github.com/gradle/gradle/raw/v8.10.0/gradle/wrapper/gradle-wrapper.jar \
                 -O "$JAR" || { echo "❌ Failed to download wrapper jar"; exit 1; }
          fi

          ./gradlew --version
          echo "✅ Gradle wrapper ready"

      # ── 5. Signing keystore ──────────────────────────────────────
      - name: Setup Signing Keystore
        run: |
          cd android/app
          if [ -z "$ANDROID_KEYSTORE_BASE64" ]; then
            echo "❌ ANDROID_KEYSTORE_BASE64 secret is missing"
            exit 1
          fi
          echo "$ANDROID_KEYSTORE_BASE64" | base64 -d > release.keystore
          keytool -list -v -keystore release.keystore \
                  -storepass "$ANDROID_KEYSTORE_PASSWORD" \
                  -alias "$ANDROID_KEY_ALIAS" 2>&1 | head -5 \
            && echo "✅ Keystore verified" \
            || echo "⚠️ Keystore check warning — build will continue"

      # ── 6. Clean ─────────────────────────────────────────────────
      - name: Clean Previous Build
        run: |
          cd android
          rm -rf app/build/outputs/bundle 2>/dev/null || true
          ./gradlew clean --no-daemon || echo "Clean completed"

      # ── 7. Build AAB ─────────────────────────────────────────────
      - name: Build Release AAB
        id: build_aab
        run: |
          cd android
          ./gradlew bundleRelease \
            --no-daemon \
            --no-build-cache \
            --no-parallel \
            --stacktrace \
            -Pandroid.injected.version.code=$VERSION_CODE \
            -Pandroid.injected.version.name=$VERSION_NAME \
            2>&1 | tee build-output.log || BUILD_FAILED=true

          if [ "$BUILD_FAILED" = "true" ]; then
            echo "❌ BUILD FAILED"
            echo "=== Kotlin/Java errors ==="
            grep "^e: " build-output.log || true
            echo "=== Last 50 lines ==="
            tail -50 build-output.log
            exit 1
          fi

          AAB=$(find app/build/outputs/bundle/release -name "*.aab" | head -1)
          if [ -z "$AAB" ]; then
            echo "❌ AAB not found after build"
            exit 1
          fi
          echo "✅ AAB built: $AAB ($(du -h "$AAB" | cut -f1))"
          echo "aab_path=$AAB" >> $GITHUB_OUTPUT

      # ── 8. Upload artifact ───────────────────────────────────────
      - name: Upload AAB Artifact
        uses: actions/upload-artifact@v4
        with:
          name: babelwords-release-aab-v${{ env.VERSION_NAME }}
          path: android/app/build/outputs/bundle/release/*.aab
          retention-days: 30

      # ── 9. GitHub Release (optional) ─────────────────────────────
      - name: Create GitHub Release
        if: env.CREATE_RELEASE == 'true' && github.event_name == 'workflow_dispatch'
        uses: softprops/action-gh-release@v1
        with:
          tag_name: v${{ env.VERSION_NAME }}
          name: BabelWords v${{ env.VERSION_NAME }}
          files: android/app/build/outputs/bundle/release/*.aab
          generate_release_notes: true
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 6. Common Errors & Fixes

| Error | Cause | Fix |
|-------|-------|-----|
| `failed to load include path .../android-35/android.jar` | compileSdk 35 not pre-installed | Use `compileSdk 34` in build.gradle |
| `Expecting a top level declaration` (`.kt:1:1`) | Corrupted `.kt` file | Check file contents — likely truncated |
| `Unresolved reference: SomeClass` | Class file missing or corrupted | Restore the referenced `.kt` file |
| `Android resource linking failed` | Deprecated gradle properties still active | Remove deprecated properties from `gradle.properties` |
| `Could not compile build file` | Syntax error in `build.gradle` | Check for unbalanced braces or bad `buildConfigField` quotes |
| `Unable to auto detect email address` | git not configured in push script | Add `git config user.email` and `git config user.name` before committing |

## 7. One-Time Keystore Generation

Run this once locally to create your signing key:

```bash
keytool -genkeypair \
  -v \
  -keystore babelwords-release.keystore \
  -alias babelwords-key \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -storepass YOUR_STORE_PASSWORD \
  -keypass YOUR_KEY_PASSWORD \
  -dname "CN=BabelWords, OU=Mobile, O=YourOrg, L=City, S=State, C=US"

# Then encode it for GitHub Secrets:
base64 -i babelwords-release.keystore | pbcopy   # macOS — pastes to clipboard
base64 babelwords-release.keystore               # Linux — prints to terminal
```

Paste the output into the `ANDROID_KEYSTORE_BASE64` secret.

## 8. Checklist Before First Run

- [ ] `android/` directory exists at repo root
- [ ] `namespace` set in `android/app/build.gradle` (required by AGP 8.x)
- [ ] `compileSdk = 34` and `targetSdk = 34` in root `build.gradle`
- [ ] No deprecated properties in `gradle.properties`
- [ ] All 4 keystore secrets added to GitHub repo
- [ ] `.kt` source files are not corrupted (not empty / truncated)
- [ ] `gradlew` is executable (`chmod +x android/gradlew`)
