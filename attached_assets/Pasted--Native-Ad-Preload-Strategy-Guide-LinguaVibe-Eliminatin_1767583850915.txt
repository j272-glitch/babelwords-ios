# Native Ad Preload Strategy Guide

## LinguaVibe - Eliminating WebView Bridge Latency for Ad Requests

---

## Problem Statement

The current ad loading flow introduces significant latency due to the multi-step WebView bridge communication:

```
Current Flow (Slow):
┌─────────────────────────────────────────────────────────────────────────┐
│ User taps button                                                        │
│      ↓                                                                  │
│ WebView loads/navigates                                                 │
│      ↓                                                                  │
│ JavaScript event fires                                                  │
│      ↓                                                                  │
│ JS sends message across WebView bridge                                  │
│      ↓                                                                  │
│ Native plugin receives message                                          │
│      ↓                                                                  │
│ Native code initiates ad load request                                   │
│      ↓                                                                  │
│ Ad network fetches creative (network latency)                           │
│      ↓                                                                  │
│ Ad ready to display                                                     │
└─────────────────────────────────────────────────────────────────────────┘
Total delay: 500ms-2000ms+ before ad fetch even begins
```

## Solution: Native-First Ad Loading

Trigger the ad request directly in the native layer (MainActivity/AppDelegate) immediately upon button press, before or alongside WebView loading. This duplicates the autoload algorithm at the native entry point.

```
Optimized Flow (Fast):
┌─────────────────────────────────────────────────────────────────────────┐
│ User taps button                                                        │
│      ↓                                                                  │
│ ┌──────────────────────────┬──────────────────────────────────────────┐ │
│ │ PARALLEL TRACK A         │ PARALLEL TRACK B                         │ │
│ │ (Native Ad Preload)      │ (WebView Loading)                        │ │
│ │                          │                                          │ │
│ │ Native immediately       │ WebView begins loading                   │ │
│ │ triggers ad request      │ JavaScript initializes                   │ │
│ │      ↓                   │      ↓                                   │ │
│ │ Ad network fetches       │ App content renders                      │ │
│ │ creative                 │                                          │ │
│ │      ↓                   │                                          │ │
│ │ Ad cached and ready      │                                          │ │
│ └──────────────────────────┴──────────────────────────────────────────┘ │
│                            ↓                                            │
│              Ad displays instantly when needed                          │
└─────────────────────────────────────────────────────────────────────────┘
Time saved: 300ms-1500ms (bridge communication eliminated)
```

## Key Implementation Points

### 1. Initialization Timing

| Phase | Android Location | iOS Location | Action |
|-------|------------------|--------------|--------|
| App Launch | `Application.onCreate()` | `AppDelegate.didFinishLaunching` | Initialize SDK |
| Activity Start | `MainActivity.onCreate()` | `viewDidLoad` | Trigger first preload |
| Button Press | Button click handler | Button tap handler | Trigger preload |

### 2. Duplicate Autoload Algorithm

The autoload algorithm should be duplicated in these locations:

1. **Application/AppDelegate level**: Initialize SDK on cold start
2. **Activity/ViewController level**: Preload on view creation  
3. **Button press handlers**: Preload alongside user action
4. **Session start**: Ensure ads ready for session

### 3. Thread Safety

Both Android and iOS implementations use atomic flags to prevent duplicate loading:

```kotlin
// Android
private val isInterstitialLoading = AtomicBoolean(false)

if (!isInterstitialLoading.compareAndSet(false, true)) {
    return // Already loading
}
```

```swift
// iOS  
private var isInterstitialLoading = false

guard !isInterstitialLoading else { return }
isInterstitialLoading = true
```

### 4. Automatic Reload After Display

Both platforms automatically preload the next ad when an ad is dismissed:

```kotlin
override fun onAdDismissedFullScreenContent() {
    interstitialAd = null
    preloadInterstitial(context) // Immediately preload next
}
```

### AdPreloadManager.kt

```kotlin
package com.linguavibe.ads

import android.app.Activity
import android.content.Context
import android.util.Log
import com.google.android.gms.ads.*
import com.google.android.gms.ads.interstitial.InterstitialAd
import com.google.android.gms.ads.interstitial.InterstitialAdLoadCallback
import com.google.android.gms.ads.rewarded.RewardedAd
import com.google.android.gms.ads.rewarded.RewardedAdLoadCallback
import java.util.concurrent.atomic.AtomicBoolean

object AdPreloadManager {
    
    private const val TAG = "AdPreloadManager"
    
    // Ad Unit IDs - Replace with production IDs
    private const val INTERSTITIAL_AD_UNIT_ID = "ca-app-pub-XXXXXXXX/YYYYYYYY"
    private const val REWARDED_AD_UNIT_ID = "ca-app-pub-XXXXXXXX/ZZZZZZZZ"
    
    // Test IDs
    private const val TEST_INTERSTITIAL_ID = "ca-app-pub-3940256099942544/1033173712"
    private const val TEST_REWARDED_ID = "ca-app-pub-3940256099942544/5224354917"
    
    private var interstitialAd: InterstitialAd? = null
    private var rewardedAd: RewardedAd? = null
    
    private val isInterstitialLoading = AtomicBoolean(false)
    private val isRewardedLoading = AtomicBoolean(false)
    private val isSdkInitialized = AtomicBoolean(false)
    
    var onInterstitialReady: (() -> Unit)? = null
    var onRewardedReady: (() -> Unit)? = null
    var onAdDismissed: (() -> Unit)? = null
    var onRewardEarned: ((type: String, amount: Int) -> Unit)? = null
    
    private var useTestAds = false
    
    fun initialize(context: Context, useTestAds: Boolean = false) {
        this.useTestAds = useTestAds
        
        if (isSdkInitialized.get()) {
            Log.d(TAG, "SDK already initialized, triggering preload")
            preloadAllAds(context)
            return
        }
        
        Log.d(TAG, "Initializing AdMob SDK...")
        
        MobileAds.initialize(context) { status ->
            isSdkInitialized.set(true)
            Log.d(TAG, "AdMob SDK initialized - beginning preload")
            preloadAllAds(context)
        }
    }
    
    fun preloadAllAds(context: Context) {
        Log.d(TAG, "Preloading all ads...")
        preloadInterstitial(context)
        preloadRewarded(context)
    }
    
    fun preloadInterstitial(context: Context) {
        if (interstitialAd != null) {
            Log.d(TAG, "Interstitial already cached")
            return
        }
        
        if (!isInterstitialLoading.compareAndSet(false, true)) {
            Log.d(TAG, "Interstitial already loading")
            return
        }
        
        val adUnitId = if (useTestAds) TEST_INTERSTITIAL_ID else INTERSTITIAL_AD_UNIT_ID
        
        InterstitialAd.load(context, adUnitId, AdRequest.Builder().build(),
            object : InterstitialAdLoadCallback() {
                override fun onAdLoaded(ad: InterstitialAd) {
                    Log.d(TAG, "Interstitial loaded")
                    interstitialAd = ad
                    isInterstitialLoading.set(false)
                    setupInterstitialCallbacks(ad, context)
                    onInterstitialReady?.invoke()
                }
                
                override fun onAdFailedToLoad(error: LoadAdError) {
                    Log.e(TAG, "Interstitial failed: ${error.message}")
                    isInterstitialLoading.set(false)
                    
                    android.os.Handler(android.os.Looper.getMainLooper())
                        .postDelayed({ preloadInterstitial(context) }, 30000)
                }
            })
    }
    
    fun preloadRewarded(context: Context) {
        if (rewardedAd != null) return
        if (!isRewardedLoading.compareAndSet(false, true)) return
        
        val adUnitId = if (useTestAds) TEST_REWARDED_ID else REWARDED_AD_UNIT_ID
        
        RewardedAd.load(context, adUnitId, AdRequest.Builder().build(),
            object : RewardedAdLoadCallback() {
                override fun onAdLoaded(ad: RewardedAd) {
                    rewardedAd = ad
                    isRewardedLoading.set(false)
                    setupRewardedCallbacks(ad, context)
                    onRewardedReady?.invoke()
                }
                
                override fun onAdFailedToLoad(error: LoadAdError) {
                    isRewardedLoading.set(false)
                    android.os.Handler(android.os.Looper.getMainLooper())
                        .postDelayed({ preloadRewarded(context) }, 30000)
                }
            })
    }
    
    private fun setupInterstitialCallbacks(ad: InterstitialAd, context: Context) {
        ad.fullScreenContentCallback = object : FullScreenContentCallback() {
            override fun onAdDismissedFullScreenContent() {
                interstitialAd = null
                onAdDismissed?.invoke()
                preloadInterstitial(context)
            }
            override fun onAdFailedToShowFullScreenContent(error: AdError) {
                interstitialAd = null
                preloadInterstitial(context)
            }
        }
    }
    
    private fun setupRewardedCallbacks(ad: RewardedAd, context: Context) {
        ad.fullScreenContentCallback = object : FullScreenContentCallback() {
            override fun onAdDismissedFullScreenContent() {
                rewardedAd = null
                onAdDismissed?.invoke()
                preloadRewarded(context)
            }
            override fun onAdFailedToShowFullScreenContent(error: AdError) {
                rewardedAd = null
                preloadRewarded(context)
            }
        }
    }
    
    fun isInterstitialReady(): Boolean = interstitialAd != null
    fun isRewardedReady(): Boolean = rewardedAd != null
    
    fun showInterstitial(activity: Activity): Boolean {
        return interstitialAd?.let { it.show(activity); true } ?: false
    }
    
    fun showRewarded(activity: Activity): Boolean {
        return rewardedAd?.let { ad ->
            ad.show(activity) { reward ->
                onRewardEarned?.invoke(reward.type, reward.amount)
            }
            true
        } ?: false
    }
    
    fun getAdStatus(): Map<String, Boolean> = mapOf(
        "interstitialReady" to isInterstitialReady(),
        "rewardedReady" to isRewardedReady(),
        "sdkInitialized" to isSdkInitialized.get()
    )
}
```

```swift
import Foundation
import GoogleMobileAds
import UIKit

@objc class AdPreloadManager: NSObject {
    
    @objc static let shared = AdPreloadManager()
    
    // Ad Unit IDs - Replace with production IDs
    private let interstitialAdUnitID = "ca-app-pub-XXXXXXXX/YYYYYYYY"
    private let rewardedAdUnitID = "ca-app-pub-XXXXXXXX/ZZZZZZZZ"
    
    // Test IDs
    private let testInterstitialID = "ca-app-pub-3940256099942544/4411468910"
    private let testRewardedID = "ca-app-pub-3940256099942544/1712485313"
    
    @objc var useTestAds: Bool = false
    
    private var interstitialAd: GADInterstitialAd?
    private var rewardedAd: GADRewardedAd?
    
    private var isInterstitialLoading = false
    private var isRewardedLoading = false
    private var isSdkInitialized = false
    
    @objc var onInterstitialReady: (() -> Void)?
    @objc var onRewardedReady: (() -> Void)?
    @objc var onAdDismissed: (() -> Void)?
    @objc var onRewardEarned: ((_ type: String, _ amount: Int) -> Void)?
    
    private override init() { super.init() }
    
    @objc func initialize(useTestAds: Bool = false) {
        self.useTestAds = useTestAds
        
        if isSdkInitialized {
            print("[AdPreloadManager] SDK initialized, triggering preload")
            preloadAllAds()
            return
        }
        
        print("[AdPreloadManager] Initializing AdMob SDK...")
        
        GADMobileAds.sharedInstance().start { [weak self] status in
            print("[AdPreloadManager] AdMob SDK initialized")
            self?.isSdkInitialized = true
            self?.preloadAllAds()
        }
    }
    
    @objc func preloadAllAds() {
        print("[AdPreloadManager] Preloading all ads...")
        preloadInterstitial()
        preloadRewarded()
    }
    
    @objc func preloadInterstitial() {
        guard interstitialAd == nil else {
            print("[AdPreloadManager] Interstitial already cached")
            return
        }
        guard !isInterstitialLoading else {
            print("[AdPreloadManager] Interstitial already loading")
            return
        }
        
        isInterstitialLoading = true
        let adUnitID = useTestAds ? testInterstitialID : interstitialAdUnitID
        
        GADInterstitialAd.load(withAdUnitID: adUnitID, request: GADRequest()) { 
            [weak self] ad, error in
            guard let self = self else { return }
            
            self.isInterstitialLoading = false
            
            if let error = error {
                print("[AdPreloadManager] Interstitial failed: \(error.localizedDescription)")
                DispatchQueue.main.asyncAfter(deadline: .now() + 30) { [weak self] in
                    self?.preloadInterstitial()
                }
                return
            }
            
            print("[AdPreloadManager] Interstitial loaded")
            self.interstitialAd = ad
            self.interstitialAd?.fullScreenContentDelegate = self
            self.onInterstitialReady?()
        }
    }
    
    @objc func preloadRewarded() {
        guard rewardedAd == nil else { return }
        guard !isRewardedLoading else { return }
        
        isRewardedLoading = true
        let adUnitID = useTestAds ? testRewardedID : rewardedAdUnitID
        
        GADRewardedAd.load(withAdUnitID: adUnitID, request: GADRequest()) { 
            [weak self] ad, error in
            guard let self = self else { return }
            
            self.isRewardedLoading = false
            
            if let error = error {
                print("[AdPreloadManager] Rewarded failed: \(error.localizedDescription)")
                DispatchQueue.main.asyncAfter(deadline: .now() + 30) { [weak self] in
                    self?.preloadRewarded()
                }
                return
            }
            
            print("[AdPreloadManager] Rewarded loaded")
            self.rewardedAd = ad
            self.rewardedAd?.fullScreenContentDelegate = self
            self.onRewardedReady?()
        }
    }
    
    @objc func isInterstitialReady() -> Bool { interstitialAd != nil }
    @objc func isRewardedReady() -> Bool { rewardedAd != nil }
    
    @objc func getAdStatus() -> [String: Bool] {
        return [
            "interstitialReady": isInterstitialReady(),
            "rewardedReady": isRewardedReady(),
            "sdkInitialized": isSdkInitialized
        ]
    }
    
    @objc func showInterstitial(from viewController: UIViewController) -> Bool {
        guard let ad = interstitialAd else {
            preloadInterstitial()
            return false
        }
        ad.present(fromRootViewController: viewController)
        return true
    }
    
    @objc func showRewarded(from viewController: UIViewController) -> Bool {
        guard let ad = rewardedAd else {
            preloadRewarded()
            return false
        }
        ad.present(fromRootViewController: viewController) { [weak self] in
            let reward = ad.adReward
            self?.onRewardEarned?(reward.type, reward.amount.intValue)
        }
        return true
    }
}

extension AdPreloadManager: GADFullScreenContentDelegate {
    
    func adDidDismissFullScreenContent(_ ad: GADFullScreenPresentingAd) {
        if ad is GADInterstitialAd {
            interstitialAd = nil
            preloadInterstitial()
        } else if ad is GADRewardedAd {
            rewardedAd = nil
            preloadRewarded()
        }
        onAdDismissed?()
    }
    
    func ad(_ ad: GADFullScreenPresentingAd, 
            didFailToPresentFullScreenContentWithError error: Error) {
        if ad is GADInterstitialAd {
            interstitialAd = nil
            preloadInterstitial()
        } else if ad is GADRewardedAd {
            rewardedAd = nil
            preloadRewarded()
        }
    }
}
```

### AdPreloadModule.swift

```swift
import Foundation
import React
import UIKit

@objc(AdPreloadModule)
class AdPreloadModule: NSObject {
    
    @objc static func requiresMainQueueSetup() -> Bool { true }
    
    @objc func triggerPreload() {
        DispatchQueue.main.async {
            AdPreloadManager.shared.preloadAllAds()
        }
    }
    
    @objc func onButtonPressed(_ buttonId: String) {
        DispatchQueue.main.async {
            switch buttonId {
            case "translate", "start_session", "conversation":
                AdPreloadManager.shared.preloadAllAds()
            default: break
            }
        }
    }
    
    @objc func showInterstitial(
        _ resolve: @escaping RCTPromiseResolveBlock,
        rejecter reject: @escaping RCTPromiseRejectBlock
    ) {
        DispatchQueue.main.async {
            guard let vc = UIApplication.shared.keyWindow?.rootViewController else {
                reject("NO_VC", "View controller not available", nil)
                return
            }
            let shown = AdPreloadManager.shared.showInterstitial(from: vc)
            resolve(shown)
        }
    }
    
    @objc func showRewarded(
        _ resolve: @escaping RCTPromiseResolveBlock,
        rejecter reject: @escaping RCTPromiseRejectBlock
    ) {
        DispatchQueue.main.async {
            guard let vc = UIApplication.shared.keyWindow?.rootViewController else {
                reject("NO_VC", "View controller not available", nil)
                return
            }
            let shown = AdPreloadManager.shared.showRewarded(from: vc)
            resolve(shown)
        }
    }
    
    @objc func getAdStatus(
        _ resolve: @escaping RCTPromiseResolveBlock,
        rejecter reject: @escaping RCTPromiseRejectBlock
    ) {
        resolve(AdPreloadManager.shared.getAdStatus())
    }
    
    @objc func isInterstitialReady(
        _ resolve: @escaping RCTPromiseResolveBlock,
        rejecter reject: @escaping RCTPromiseRejectBlock
```

## JavaScript/TypeScript Integration

### AdPreloadBridge.ts

```typescript
import { NativeModules, NativeEventEmitter, Platform } from 'react-native';

const { AdPreloadModule } = NativeModules;

interface AdStatus {
  interstitialReady: boolean;
  rewardedReady: boolean;
  sdkInitialized: boolean;
}

interface NativeAdBridge {
  onAdReady?: (adType: string) => void;
  onAdDismissed?: () => void;
  onRewardEarned?: (type: string, amount: number) => void;
}

declare global {
  interface Window {
    NativeAdBridge?: NativeAdBridge;
  }
}

class AdPreloadBridge {
  
  onAdReady?: (adType: string) => void;
  onAdDismissed?: () => void;
  onRewardEarned?: (type: string, amount: number) => void;
  
  constructor() {
    this.setupGlobalBridge();
  }
  
  private setupGlobalBridge(): void {
    if (typeof window !== 'undefined') {
      window.NativeAdBridge = {
        onAdReady: (adType: string) => {
          console.log(`[AdPreloadBridge] Ad ready: ${adType}`);
          this.onAdReady?.(adType);
        },
        onAdDismissed: () => {
          console.log('[AdPreloadBridge] Ad dismissed');
          this.onAdDismissed?.();
        },
        onRewardEarned: (type: string, amount: number) => {
          console.log(`[AdPreloadBridge] Reward earned: ${amount} ${type}`);
          this.onRewardEarned?.(type, amount);
        }
      };
    }
  }
  
  // Trigger ad preload in native layer
  triggerPreload(): void {
    AdPreloadModule?.triggerPreload();
  }
  
  // Notify native layer of button press
  onButtonPressed(buttonId: string): void {
    AdPreloadModule?.onButtonPressed(buttonId);
  }
  
  async showInterstitial(): Promise<boolean> {
    if (!AdPreloadModule) return false;
    return AdPreloadModule.showInterstitial();
  }
  
  async showRewarded(): Promise<boolean> {
    if (!AdPreloadModule) return false;
    return AdPreloadModule.showRewarded();
  }
  
  async getAdStatus(): Promise<AdStatus> {
    if (!AdPreloadModule) {
      return { interstitialReady: false, rewardedReady: false, sdkInitialized: false };
    }
    return AdPreloadModule.getAdStatus();
  }
  
  async isInterstitialReady(): Promise<boolean> {
    if (!AdPreloadModule) return false;
    return AdPreloadModule.isInterstitialReady();
  }
  
  async isRewardedReady(): Promise<boolean> {
    if (!AdPreloadModule) return false;
    return AdPreloadModule.isRewardedReady();
  }
}

export const adPreloadBridge = new AdPreloadBridge();
export default adPreloadBridge;
```

### Troubleshooting Guide

| Issue | Cause | Solution |
|-------|-------|----------|
| Ads not loading | SDK not initialized | Check initialization order in onCreate/didFinishLaunching |
| Ads not loading | Wrong ad unit IDs | Verify production vs test IDs |
| Duplicate requests | Missing atomic flags | Verify AtomicBoolean/guard checks |

## Summary

This implementation eliminates WebView bridge latency by:

1. **Triggering ad requests in native code** immediately on button press
2. **Running ad loading in parallel** with WebView navigation
3. **Duplicating the autoload algorithm** at the native entry point
4. **Caching ads** so they're instantly available when needed
5. **Notifying WebView** via JavaScript injection when ads are ready

The result is significantly faster ad display times and improved user experience.

## Quick Reference

### Android Quick Start

1. Add `AdPreloadManager.kt` to `android/app/src/main/java/com/linguavibe/ads/`
2. Call `AdPreloadManager.initialize(this, true)` in `MainActivity.onCreate()`
3. Call `AdPreloadManager.preloadAllAds(this)` on button press
4. Use `AdPreloadManager.showInterstitial(activity)` to display

1. Add `AdPreloadManager.swift` to `ios/LinguaVibe/`
2. Call `AdPreloadManager.shared.initialize(useTestAds: true)` in `AppDelegate.didFinishLaunchingWithOptions`
3. Call `AdPreloadManager.shared.preloadAllAds()` on button press
4. Use `AdPreloadManager.shared.showInterstitial(from: viewController)` to display
