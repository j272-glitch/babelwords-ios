# Android Ad Preload & Guaranteed-Show Guide

**Goal:** fix the *"requests are filling but 0 impressions"* problem by **preloading
ads ahead of time** and **guaranteeing a loaded ad is actually shown**.

This is a **native-Android-only** change (the separate Kotlin WebView repo built by
GitHub Actions `android-sdk-update-v25.yml`). **No web app changes are required** — the
web app already calls the bridge and listens for all the callbacks below.

---

## 1. Why this is happening (read first)

In your AdMob report: **949 requests, 33% match rate, 0 impressions.**

- **Match rate 33%** = ~1 in 3 requests *got an ad* (fill is working — including India).
- **0 impressions** = none of those loaded ads were ever **displayed**.

So this is **not** a fill problem and **not** a geography problem. It's a
**"loaded-but-never-shown"** problem. The typical cause:

> The app requests an ad **at the moment it wants to show it**. The ad isn't ready
> yet, so `show` fails, the SDK then loads it in the background — but that
> now-loaded ad is **never shown**. It counts as a matched request, then **expires**
> (interstitials expire ~1 hour), producing impressions = 0.

**The fix:** always keep an ad **preloaded** so it's ready *before* the show moment,
**reload immediately** after every show/dismiss/failure, and make `show()` robust.

---

## 2. The bridge contract (must match the web app exactly)

The web app calls these **bridge methods** (expose via `@JavascriptInterface`). Return
a **String** so the web can read it synchronously:

| Method | Returns | Meaning |
| --- | --- | --- |
| `initialize()` | — | Init AdMob + start first preload |
| `isInterstitialReady()` | `"true"` / `"false"` | Is an interstitial loaded right now |
| `isRewardedReady()` | `"true"` / `"false"` | Is a rewarded loaded right now |
| `loadInterstitial()` | — | Start/ensure an interstitial preload |
| `loadRewarded()` | — | Start/ensure a rewarded preload |
| `showInterstitial()` | `"true"` / `"not_ready"` | Show if ready; else `"not_ready"` + kick a load |
| `showRewarded()` | `"true"` / `"not_ready"` | Show if ready; else `"not_ready"` + kick a load |
| `loadInterstitialAndShow()` | — | Show now if ready; otherwise load then show once ready |
| `loadRewardedAndShow()` | — | Same, for rewarded |

> The web treats a return of `false` / `"false"` / `"not_ready"` as "not shown" and
> waits for a callback. So when ready, return **`"true"`**; when not, return
> **`"not_ready"`** and immediately start a load.

The web app **listens for these callbacks** — your native code **must call them** on
the WebView (via `evaluateJavascript`, on the UI thread):

| Callback (JS function) | When to call it |
| --- | --- |
| `onInterstitialReady()` | An interstitial finished loading |
| `onInterstitialLoadFailed(error, code)` | Interstitial load failed |
| `onInterstitialClosed()` | Interstitial was shown **and dismissed** |
| `onInterstitialFailedToShow(error, code)` | `show()` was called but failed to display |
| `onRewardedReady()` | A rewarded finished loading |
| `onRewardedLoadFailed(error, code)` | Rewarded load failed |
| `onRewardEarned(rewardType, rewardAmount)` | User earned the reward |
| `onRewardedClosed()` | Rewarded dismissed **without** earning a reward |
| `onRewardedFailedToShow(error, code)` | Rewarded `show()` failed to display |

Getting these callbacks right is what makes impressions register and the web UI
unblock correctly.

---

## 3. Core rules for guaranteed show

1. **Preload on startup** — after `MobileAds.initialize()` **and** after consent is
   gathered, immediately load one interstitial and one rewarded.
2. **Reload after every close/fail** — in `onAdDismissedFullScreenContent` **and**
   `onAdFailedToShowFullScreenContent`, start loading the next ad right away. Always
   keep one in the chamber.
3. **Show on the UI thread with a valid Activity** — `ad.show(activity)` must run on
   the main thread with the **current resumed Activity**, never a stale/destroyed one.
4. **Null the ad after showing** — an ad object can only be shown **once**. Set it to
   `null` immediately after `show()` and load a fresh one.
5. **Handle expiration** — interstitial/rewarded ads go stale after ~1 hour. Track the
   load time; if an ad is older than ~50 minutes when you go to show it, discard and
   reload (and refresh proactively while the app is foregrounded).
6. **Guard against duplicate loads** — use an `isLoading` flag so overlapping calls
   don't fire multiple `loadAd()`s (which inflate request counts and waste fill).
7. **Retry load failures with backoff** — on load failure, retry with exponential
   backoff (e.g. 2s, 4s, 8s … cap ~64s) a limited number of times.
8. **Always fire a callback** — never leave the web "waiting." Every show path must end
   in `onAdDismissed`/`onRewardEarned`/`onFailedToShow`.

## 4. Reference implementation (Kotlin)

Adapt this to your existing `AdBridge.kt` / ad manager. Shown for interstitial;
mirror the same pattern for rewarded (`RewardedAd`, `onUserEarnedReward`).

### 4.1 A small AdManager that always keeps one loaded

```kotlin
class InterstitialManager(
    private val appContext: Context,
    private val adUnitId: String,            // ca-app-pub-9991891515643313/5076005693
    private val notifyJs: (String) -> Unit   // calls evaluateJavascript on UI thread
) {
    private var ad: InterstitialAd? = null
    private var isLoading = false
    private var loadedAtMs = 0L
    private var retryCount = 0
    private var showOnLoad = false           // for loadInterstitialAndShow()
    private val mainHandler = Handler(Looper.getMainLooper())

    private val MAX_AGE_MS = 50 * 60 * 1000L // refresh before the ~1h expiry
    private val MAX_RETRIES = 5

    fun isReady(): Boolean =
        ad != null && (System.currentTimeMillis() - loadedAtMs) < MAX_AGE_MS

    /** Preload. Safe to call repeatedly. */
    fun load() {
        if (isLoading || isReady()) return
        isLoading = true
        mainHandler.post {
            val request = AdRequest.Builder().build()
            InterstitialAd.load(appContext, adUnitId, request,
                object : InterstitialAdLoadCallback() {
                    override fun onAdLoaded(loaded: InterstitialAd) {
                        ad = loaded
                        loadedAtMs = System.currentTimeMillis()
                        isLoading = false
                        retryCount = 0
                        attachShowCallbacks(loaded)
                        notifyJs("onInterstitialReady()")
                        if (showOnLoad) { showOnLoad = false; show() }
                    }
                    override fun onAdFailedToLoad(err: LoadAdError) {
                        ad = null
                        isLoading = false
                        notifyJs("onInterstitialLoadFailed('${esc(err.message)}', ${err.code})")
                        scheduleRetry()
                    }
                })
        }
    }

    private fun scheduleRetry() {
        if (retryCount >= MAX_RETRIES) return
        val delay = (1L shl retryCount) * 2000L   // 2s,4s,8s,...
        retryCount++
        mainHandler.postDelayed({ load() }, delay)
    }

    /** Returns "true" if shown, "not_ready" otherwise (and kicks a load). */
    fun show(): String {
        if (!isReady()) {
            load()
            return "not_ready"
        }
        val activity = ActivityProvider.current()   // current RESUMED activity
        if (activity == null) {
            notifyJs("onInterstitialFailedToShow('no_activity', -10)")
            return "not_ready"
        }
        mainHandler.post { ad?.show(activity) }
        return "true"
    }

    /** Show now if ready, else show as soon as the next load finishes. */
    fun loadAndShow() {
        if (isReady()) { show() } else { showOnLoad = true; load() }
    }

    private fun attachShowCallbacks(loaded: InterstitialAd) {
        loaded.fullScreenContentCallback = object : FullScreenContentCallback() {
            override fun onAdShowedFullScreenContent() {
                // impression will register here
            }
            override fun onAdDismissedFullScreenContent() {
                ad = null
                notifyJs("onInterstitialClosed()")
                load()                       // ALWAYS reload the next one
            }
            override fun onAdFailedToShowFullScreenContent(e: AdError) {
                ad = null
                notifyJs("onInterstitialFailedToShow('${esc(e.message)}', ${e.code})")
                load()                       // reload so the next attempt can succeed
            }
        }
    }

    private fun esc(s: String?) = (s ?: "").replace("'", "\\'")
}
```

### 4.2 Calling the JS callbacks safely (UI thread + WebView)

```kotlin
fun notifyJs(call: String) {
    webView.post { webView.evaluateJavascript("window.$call;", null) }
}
```

- Always run `evaluateJavascript` on the WebView's thread (`webView.post { ... }`).
- Wrap with `if (typeof window.$fn === 'function')` on the JS side if you want extra
  safety — but the web app already defines all these functions.

### 4.3 Tracking the current Activity (so show() never uses a dead one)

```kotlin
object ActivityProvider {
    private var ref: WeakReference<Activity>? = null
    fun current(): Activity? = ref?.get()?.takeIf { !it.isFinishing && !it.isDestroyed }
    // register an Application.ActivityLifecycleCallbacks and set ref in onActivityResumed
}
```

### 4.4 Bridge methods (`@JavascriptInterface`)

```kotlin
@JavascriptInterface fun isInterstitialReady() = if (interstitial.isReady()) "true" else "false"
@JavascriptInterface fun loadInterstitial() { interstitial.load() }
@JavascriptInterface fun showInterstitial(): String = interstitial.show()
@JavascriptInterface fun loadInterstitialAndShow() { interstitial.loadAndShow() }
// mirror for rewarded…
```

> For **rewarded**, call `rewardedAd.show(activity) { rewardItem -> notifyJs(
> "onRewardEarned('${rewardItem.type}', ${rewardItem.amount})") }`, fire
> `onRewardedClosed()` in `onAdDismissedFullScreenContent` **only if no reward was
> earned**, and reload after dismiss/fail just like interstitial.

## 5. Startup sequence (order matters)

```kotlin
MobileAds.initialize(this) {
    // 1) gather/forward consent (UMP) FIRST — required for EU fill
    // 2) then preload both formats so they're ready before any show
    interstitial.load()
    rewarded.load()
}
```

- Do **not** load ads before consent is resolved.
- After this, an ad should almost always be "ready" by the time the user hits the
  free-translation limit.

## 6. Testing (prove impressions register)

1. **Real device, release build** (mediation can behave differently in debug).
2. Watch logcat:
   ```
   adb logcat | grep -iE "Ads|interstitial|rewarded|unity|vungle|impression|FullScreen"
   ```
   You want to see, in order: load success → `onAdShowedFullScreenContent` →
   `onAdDismissedFullScreenContent` → next load. If you see loads but never
   `onAdShowed...`, the show path is still broken.
3. Run the **AdMob Mediation Test Suite** — it forces a show and confirms each adapter
   (Google / Unity / Liftoff) can actually display.
4. In the app: hit the free limit → interstitial should appear **immediately** (because
   it was preloaded). Rewarded should grant the 30-minute unlimited window.
5. Check **AdMob → Mediation report** over the next day: **impressions should now be
   > 0** and roughly track your match rate.

- [ ] **Reload** in both `onAdDismissedFullScreenContent` **and**
