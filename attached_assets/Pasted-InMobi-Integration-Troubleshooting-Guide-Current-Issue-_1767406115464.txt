InMobi Integration Troubleshooting Guide
Current Issue
InMobi interstitial ads are failing with "The InMobi SDK encountered an internal error." The waterfall correctly falls back to AdMob, but InMobi impressions are not being recorded.

Required Android App Changes
1. Fix JavaScript Interface Name (CRITICAL)
File: MainActivity.kt (line 368)

// BEFORE (incorrect):

// AFTER (correct):
webView.addJavascriptInterface(adWaterfallBridge, "AndroidAdBridge")
This ensures the web app can communicate with the native ad bridge.

3. Verify InMobi Initialization
File: AdWaterfallBridge.kt

Ensure the InMobi SDK is properly initialized with consent:

private fun initializeInMobi() {
    val activity = activityRef.get() ?: return
    
    // CRITICAL: Consent object must be properly configured
    val consentObject = JSONObject().apply {
        put("gdpr_consent_available", AdConfig.Privacy.gdprConsent)
        put("gdpr", if (AdConfig.Privacy.gdprConsent) "1" else "0")
    }
    
    InMobiSdk.init(activity, AdConfig.InMobi.ACCOUNT_ID, consentObject, object : SdkInitializationListener {
        override fun onInitializationComplete(error: Error?) {
            if (error == null) {
                isInMobiInitialized = true
                Log.d(AdConfig.LOG_TAG, "InMobi SDK initialized successfully")
                
                // Enable debug logging to see detailed errors
                if (AdConfig.DEBUG_MODE) {
                    InMobiSdk.setLogLevel(InMobiSdk.LogLevel.DEBUG)
                }
                
                // Pre-load ads after initialization
                preloadInMobiInterstitial()
                preloadInMobiRewarded()
            } else {
                Log.e(AdConfig.LOG_TAG, "InMobi init failed: ${error.message}")
            }
        }
    })
}
4. Add Initialization Delay for Interstitials
InMobi may need time to fully initialize before loading ads. Add a delay:

private fun preloadInMobiInterstitial() {
    if (!isInMobiInitialized) {
        Log.d(AdConfig.LOG_TAG, "InMobi not initialized yet, delaying interstitial load")
        Handler(Looper.getMainLooper()).postDelayed({
            preloadInMobiInterstitial()
        }, 1000)
        return
    }
    
    // Proceed with loading...
}

7. Add Error Details to Interstitial Listener
File: AdWaterfallBridge.kt

Get more details about why InMobi ads fail:

private fun preloadInMobiInterstitial() {
    val activity = activityRef.get() ?: return
    
    inMobiInterstitial = InMobiInterstitial(
        activity, 
        AdConfig.InMobi.Placements.INTERSTITIAL
    ).apply {
        setListener(object : InterstitialAdEventListener() {
            override fun onAdLoadSucceeded(ad: InMobiInterstitial, info: AdMetaInfo) {
                Log.d(AdConfig.LOG_TAG, "InMobi interstitial loaded - bid: ${info.bidInfo}")
                isInMobiInterstitialReady = true
            }
            
            override fun onAdLoadFailed(ad: InMobiInterstitial, status: InMobiAdRequestStatus) {
                // Log detailed error information
                Log.e(AdConfig.LOG_TAG, "InMobi interstitial failed:")
                Log.e(AdConfig.LOG_TAG, "  Status Code: ${status.statusCode}")
                Log.e(AdConfig.LOG_TAG, "  Message: ${status.message}")
                Log.e(AdConfig.LOG_TAG, "  Placement: ${AdConfig.InMobi.Placements.INTERSTITIAL}")
                
                // Fall back to AdMob
                preloadAdMobInterstitial()
            }
            
            override fun onAdDisplayed(ad: InMobiInterstitial, info: AdMetaInfo) {
                Log.d(AdConfig.LOG_TAG, "InMobi interstitial displayed")
                recordImpression(AdNetwork.INMOBI, "interstitial")
            }
            
            override fun onAdDismissed(ad: InMobiInterstitial) {
                Log.d(AdConfig.LOG_TAG, "InMobi interstitial dismissed")
                isInMobiInterstitialReady = false
                preloadInMobiInterstitial() // Reload for next time
            }
        })
    }
    
    inMobiInterstitial?.load()
}

InMobi "Internal Error" Common Causes
Cause	Solution
Account pending approval	Wait for InMobi to approve your account
Placement not active	Activate placements in InMobi dashboard
Missing consent	Ensure GDPR consent is passed correctly
SDK version mismatch	Update to latest InMobi SDK (10.6.7+)
Network issues	Check device has internet connectivity
Rate limiting	Wait and retry (new accounts have limits)
